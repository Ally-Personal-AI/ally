# Ally Vision

Ally is a private, persistent, user-owned artificial intelligence that develops
a deep understanding of the individual, household, or organization it serves.

Ally should remember history, reason with strong interchangeable models,
interact naturally, use software and tools, learn new capabilities, and act
within explicit user-defined boundaries.

## North star

Ally should become more useful the longer it is used without making the user's
continued access dependent on a vendor, cloud model, or subscription.

## Product promise

- Models are replaceable.
- Memory persists.
- Tools are extensible.
- Policies are programmable.
- Data belongs to the user.
- Private intelligence is not sent to external model providers.
- The assistant evolves.

The system is successful when users can own, inspect, move, modify, back up,
and continue operating their personal intelligence independently.
