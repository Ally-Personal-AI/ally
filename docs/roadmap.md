# Roadmap

The dependency order for Ally is:

1. Foundation
2. Local conversation
3. Long-term memory
4. Personal knowledge
5. Tools
6. Skills
7. Reliable agency
8. Proactivity
9. Voice
10. Multi-user households
11. Extension ecosystem
12. Dedicated hardware
13. Computer control
14. Physical-world integration
15. Distributed Ally

## Ally 0.1

The first meaningful release target is a completely local, model-independent personal AI with persistent conversations, inspectable long-term memory, personal document knowledge, optional internet research, explicit local-data boundaries, and an evaluation suite.

The first engineering priority is not autonomy. It is building a local assistant whose usefulness compounds because it remembers accurately.
