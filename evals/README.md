# Ally Evaluations

Ally will treat evaluations as a first-class product subsystem.

The initial evaluation suite will grow to cover:

- instruction following
- model-provider compatibility
- memory precision and recall
- temporal memory correctness
- provenance quality
- tool selection
- permission enforcement
- task completion and verification
- privacy and data-boundary regressions

Evaluation fixtures must use synthetic data unless a contributor deliberately
adds appropriately licensed public data. Personal user data must never enter
the repository.
